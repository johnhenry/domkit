domkit

A live gallery of @johnhenry/domkit's modules, each running the real source from ../src/ in its own isolated iframe (so independent custom elements can coexist on one page without colliding). Nothing here is a mockup — every card is the actual module, actually running.

Drop-in UI elements

tabbed-ui

Accessible tabs from plain markup: ARIA wiring, arrow keys, Home/End, disabled tabs.

stylable-select

A fully stylable listbox with a native select's API, form behavior, keyboard, and events.

infinite-combo-box

An accessible autocomplete: filters its own options, or searches a URL or function as you type.

hot-key

Keyboard shortcuts for a native <dialog> (polyfilling closedby), a popover, or any invoker command.

drill-menu

A list that drills into sub-screens and back, with keyboard support, focus restoration, and hash sync.

code-color

Syntax highlighting with the CSS Custom Highlight API: the text is never modified, and it re-highlights as you edit.

Responsive without media-query plumbing src/matchable/*

Resize your browser window — these frames re-evaluate their media queries live.

query-container

Swap the rendered wrapper element entirely by media query.

attribute-provider

Apply classes/styles/attributes to existing children by media query.

Persisted UI state src/cyclable/*

localstorage-cycler/localstorage-attribute-cycler (the engine both elements share) have no visible output of their own — see the cyclable readme.

attribute-cycler

Buttons that cycle a persisted class (or any attribute) on <html>, synced across tabs and drivable by invoker commands.

Wiring things up from markup src/definable/*

definetag has no visible output of its own (it's the curried customElements.define primitive the others build on) — see the definable readme.

define-component

Register a custom element from a module's export, or from a <template> written in the page.

polyfill-window

Load a module by URL, assign its export to a global. No visible output — check window.shout in the frame's console.

until-window-load

Removes a "hidden until loaded" class once window has loaded and every <define-component> has finished.

Utilities timing · collections

delay (milliseconds, or one frame at a given fps) and clamp are plain functions with nothing to show; frame-timer below is the clock-shaped version of delay({ fps }).

frame-timer

A clock element: steady tick events, with play()/pause() like a media element.

live-query-selector

An auto-updating array of the elements matching a selector, with a change event and a .stop() to disconnect it.

App bootstrap src/hydratable/*

mounts

Framework-agnostic body-first/body-last mount points (Solid/Vue/React-style).

hydratable

A generic async hydration mixin, with an undo (dehydrate()).

Experimental src/experimental/*

Sketches, not supported API — see the experimental readme for what that means.

imagedata-emitter → pixel-shader → canvas-renderer

A render-event pixel pipeline: emit an ImageData, transform it on the way up, draw it.

animate-paths

Animated SVG stroke drawing, driven by attributes.

xy-grapher

Scatter plot from a JSON data attribute, using its first child as the point template.

chernoff-face

Parametric faces as a data-visualization technique.

Every card above imports directly from this repo's src/ — open this page through a static file server (module imports don't resolve over file://): run npm run serve from the repo root, then open http://localhost:4719/demo/. The recipes show modules working together.
