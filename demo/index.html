domkit

A live gallery of @johnhenry/domkit's modules, each running the real source from ../src/ in its own isolated iframe (so independent custom elements can coexist on one page without colliding). Nothing here is a mockup — every card is the actual module, actually running.

Four coherent clusters briefly lived as their own npm packages (definable, matchable, cyclable, hydratable) before being folded back in as namespaced subpaths under this one package — same code, one repo, one version. Everything below is live again.

Defining custom elements src/definable/*

definetag has no visible output of its own (it's the curried customElements.define primitive the others build on) — see its readme instead.

define-component.component

Load a module by URL, register its export as a custom element. Own demo — bootstraps itself via this exact pattern.

define-component-by-content.component

Define a custom element from an inline HTML string attribute.

polyfill-window.component

Load a module by URL, assign its export to a global — not a custom-element registrar.

until-window-load

Removes a "hidden until loaded" class once window fires load.

Responsive containers src/matchable/*

Resize your browser window — these frames re-evaluate their media queries live.

query-container.component

Swap the rendered child element entirely by media query.

attribute-provider.component

Apply classes/styles/attributes to existing children by media query.

Shadow DOM & lifecycle shadow-dom.component · internal-timer.component

shadow-dom.component

Deprecated alias for domable's simple-element shadowOpen.

internal-timer.component

A frame-paced tick emitter with pause/resume — a worked example of the disconnectedCallback lifecycle-symmetry fixes from the completeness audit.

Widgets includes src/cyclable/*

localstorage-cycler/localstorage-class-cycler (the engine both class-cycler variants share) have no visible output of their own — see their readme.

class-cycler.component

Global-function class cycler, persisted to localStorage.

class-cycler.button.component

Self-contained button variant.

hotkey-modal.dialog.component

A native <dialog> opened/closed by a keyboard shortcut.

menu.component + hash.mjs

Keyboard-navigable stateful menu, synced to location.hash via its attach()/detach() companion.

stylable-select.component

A <select>-like element whose options can actually be styled.

tabbed-ui.component

Tabs/panels element, matched by position.

infinite-combo.component

A combo-box that loads more options on demand.

event-consumer.component

Declaratively wire event listeners without JS setup code.

code-color.component

Syntax-highlights its contents, re-highlighting on change.

Visual/canvas experiments animate-paths.component · xy-grapher.component · chernoff-face.component

animate-paths.component

SVG path animation — the domkit logo, animated.

xy-grapher.component

Known broken — component.mjs calls a genSVG() function that's never defined anywhere, so render() throws. Inherited from lib, predates this package. The demo used to silently mask this by accidentally registering chernoff-face.component's component under the xy-grapher tag (a copy-paste bug in the original demo.html) — fixed to register the real component, which surfaces the render bug instead of hiding it.

chernoff-face.component

Parametric faces as a data-visualization technique.

graph.component

Unimplemented placeholder — kept per the repo's no-deletion policy.

canvasrenderer.component, pixelshader.component, and imagedata-emitter.component have no README or demo file yet (demo-grade experiments, carried over as-is from the original extraction) — not included here to avoid guessing at an undocumented API. See their source under src/. (brains, a similarly-undocumented input-abstraction experiment, was removed outright rather than kept around unlabeled.)

DOM ⇄ React interop domable · src/hydratable/*

domToReact/reactToDom are domable's own conversion pair, shown here since domkit depends on it directly (not vendored). mounts/hydratable are domkit's own again.

domable's domToReact / reactToDom

domkit has no conversions of its own — it depends on @johnhenry/domable for these.

mounts

Framework-agnostic body-first/body-last mount points (Solid/Vue/React-style).

hydratable

A generic async hydration mixin.

Foundation create-mutable-nodelist · live-query-selector

create-mutable-nodelist

A push/pop/shift/unshift-able NodeList-like collection.

live-query-selector

An auto-updating live collection matching a selector, with a .stop() to disconnect it.
