domkit

A live gallery of @johnhenry/domkit's modules, each running the real source from ../src/ in its own isolated iframe (so independent custom elements can coexist on one page without colliding). Nothing here is a mockup — every card is the actual module, actually running.

Drop-in UI Responsive Persisted UI state Wiring from markup Utilities App bootstrap Deprecated Experimental Source

Drop-in UI elements

tabbed-ui

Accessible tabs from plain markup: ARIA wiring, arrow keys, Home/End, disabled tabs.

stylable-select

A fully stylable listbox with a native select's API, form behavior, keyboard, and events.

combo-box

An accessible autocomplete: filters its own options, or searches a URL or function as you type.

hotkey-dialog

Toggles a native <dialog> with a keyboard shortcut, polyfilling closedby.

menu-component + hash.mjs

Keyboard-navigable stateful menu, synced to location.hash via its attach()/detach() companion.

code-color

Syntax-highlights its contents (HTML, CSS, or JS), re-highlighting on change.

Responsive without media-query plumbing src/matchable/*

Resize your browser window — these frames re-evaluate their media queries live.

query-container

Swap the rendered wrapper element entirely by media query.

attribute-provider

Apply classes/styles/attributes to existing children by media query.

Persisted UI state src/cyclable/*

localstorage-cycler/localstorage-class-cycler (the engine both elements share) have no visible output of their own — see the cyclable readme.

class-cycler

Buttons that cycle a persisted class on <html>, synced across tabs and drivable by invoker commands.

Wiring things up from markup src/definable/* · event-consumer

definetag has no visible output of its own (it's the curried customElements.define primitive the others build on) — see the definable readme.

define-component

Load a module by URL, register its export as a custom element.

define-component-by-content

Define a custom element from an inline HTML string attribute.

polyfill-window

Load a module by URL, assign its export to a global. No visible output — check window.shout in the frame's console.

until-window-load

Removes a "hidden until loaded" class once window fires load.

event-consumer

Declaratively wire event listeners without JS setup code.

Utilities timing · collections

delay, frame-delay, and clamp are plain functions with nothing to show — internal-timer below is built on the first two.

internal-timer

A frame-paced tick emitter with pause/resume.

live-query-selector

An auto-updating live collection matching a selector, with a .stop() to disconnect it.

create-mutable-nodelist

A push/pop/shift/unshift-able NodeList-like collection.

App bootstrap src/hydratable/*

mounts

Framework-agnostic body-first/body-last mount points (Solid/Vue/React-style).

hydratable

A generic async hydration mixin, with an undo (dehydrate()).

domable's domToReact / reactToDom

Not part of domkit — these live in its dependency, @johnhenry/domable. Shown here because it's installed alongside.

Deprecated

shadow-dom

Alias for domable's simple-element shadowOpen`<slot />`. Use domable directly.

Experimental src/experimental/*

Sketches, not supported API — see the experimental readme for what that means.

imagedata-emitter → pixel-shader → canvas-renderer

A render-event pixel pipeline: emit an ImageData, transform it on the way up, draw it.

animate-paths

Animated SVG stroke drawing, driven by attributes.

xy-grapher

Scatter plot from a JSON data attribute, using its first child as the point template.

chernoff-face

Parametric faces as a data-visualization technique.

Every card above imports directly from this repo's src/ — open this page through a static file server (module imports don't resolve over file://), e.g. npx http-server . from the repo root, then visit /demo/. See the root README for the full module index and install instructions.
