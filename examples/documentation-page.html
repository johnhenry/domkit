Documentation page

The parts of a docs page that usually need a framework: code samples in tabs, highlighted without touching the markup, and a list that becomes numbered steps when there's room. Written as plain HTML, the way a Markdown renderer would emit it.

Install

<script type="module" src="https://esm.sh/@johnhenry/domkit/tabbed-ui/global.mjs"></script>
 
// npm install @johnhenry/domkit
import "@johnhenry/domkit/tabbed-ui/global.mjs";
 
/* Style it like anything else */
tabbed-ui [role="tab"][aria-selected="true"] {
  border-bottom: 2px solid currentColor;
}

Getting started

  • Add one <script> tag per element you use.
  • Write the element's markup: it reads fine even before the script loads.
  • Style it with ordinary CSS, and listen for the same events as native controls.
    •

    Narrow the window below 640px: the steps turn back into a bulleted list, because on a phone they read as tips, not a sequence.
