domkit recipes

Complete pages that combine domkit modules the way a real site would. Each is plain HTML with no build step: view the source.

  • Theme switcher: class-cycler with color-scheme, synced across tabs
  • Command palette: hotkey-dialog + combo-box, on ⌘K
  • Settings panel: one <form> across drill-menu screens, with stylable-select, combo-box, and class-cycler
  • Documentation page: tabbed-ui code samples highlighted by code-color, and query-container
  • Game loop: frame-timer driving an animation

The module gallery shows each module on its own.
